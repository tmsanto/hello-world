# Modelos (opcional)

| Arquivo | Para quê |
|---|---|
| `dc96.pdf` | Formulário oficial DC-96 (DC-96-T 01/25) **em branco**. Com ele, o botão "PDF oficial" preenche o próprio formulário. Vem no zip de instalação. |
| `relatorio_fotografico.docx` | Modelo Word do relatório fotográfico (mantém cabeçalho, rodapé e logotipo). |
| `problemas_encontrados.docx` | Modelo Word de problemas encontrados. |

Sem estes arquivos o sistema continua funcionando: o Word sai com um cabeçalho
simples e o botão do PDF oficial da DC-96 some.

Os `.pdf` e `.docx` desta pasta não vão para o git porque o repositório é público.
